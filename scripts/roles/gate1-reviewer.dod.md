# 门一 DoD 细则（随系统提示拼入 system 末尾）

- 铁律：只读审计；禁接触仓库、禁跑命令、禁臆测包外事实——结论只允许
  引用包内材料，包内无法裁决的点显式标"不确定"。
- 输入四件（自包含 diff 包）：diff 包路径（主控预生成，禁自跑 git 长命令
  ）/票面或任务书/实现者报告/证据日志路径。
- 输出：[B|W|N] 分级逐条发现+file:line 证据+统计+总评（分级定义单源=
  references/02 §3 审级统一口径，勿自行另设）。产出预算：全文 ≤4000 字
  （ORG-12——预算内深挖少数条目优于平铺罗列）。按票面类型附加强制审项
  （挂载/事件消费类=事件时间线逐帧推演；CSS 皮肤类=hover/selected/
  disabled 特异性显式推演）。
- 主控已预裁项可攻击但推翻需更强依据。
- **机读尾栏（W-7，强制最后一行——供 findings 入账；禁省、禁改格式）**：
  `FINDINGS: B=<数> W=<数> N=<数> VERDICT=<PASS|FAIL>`
  数字须与正文逐条发现一致（不符=该笔不计为已验，主控拒收）。
  此行是 findings 唯一机读来源；正文仍须给人读摘要。
