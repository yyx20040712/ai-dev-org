# 任务书型件：结项/交付型（close）

## 1. 型名定义

承载结项/交付批：批后验收、终态对账、交接与挂账移交，落点为可审计的闭卷实录。

## 2. 型特定段差分

### 2.1 预裁决样例（型典型歧义）

- {{对账口径两方向不可自洽}} → {{暴露交裁决，禁选边消化}}
- {{交接生效条件}} → {{接手方完成开工体检并签署留档}}
- {{闭卷范围}} → {{显式列结项面与不结项面，禁模糊}}

### 2.2 验收面差分

- 终态数字与账本/台账翻状态一致；账本既有行零改写
- CI 四要素（如涉 push 批）：run id、commit、必需 job 与最终状态逐项核销
- 交接件自包含：体检口径/真相/管道/授权/挂账/索引/开工第一句

### 2.3 报告口径差分

- 终态实录（数字+命令+退出码）与移交挂账清单分列
- 断点即记：暂停/终止/阻塞当场落账，不留事后补叙

## 3. 叠加条款（按需保留）

- 单点配置：本批若只改 {{单个配置键/默认值}}，逐处列改动点与回读验证命令，禁批量扫改。
- CI：本批若改工作流/门禁脚本，逐 job 列必需项与预期状态，批后以 run 实录核销。
- 安全敏感：本批若涉 {{密钥/凭证/权限面}}，只列面不录值，处置走既有登记/轮换流程。
- 资源风险：本批若涉 {{额度/时长/外部配额}}，先落预算与止损线，超线即停手上报。
