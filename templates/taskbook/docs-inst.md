# 任务书型件：文档/制度型（docs-inst）

## 1. 型名定义

承载 ruling 落账后的宪法/文档/制度同步批：改文档不改行为，落点为规范面与制度面一致。

## 2. 型特定段差分

### 2.1 预裁决样例（型典型歧义）

- {{历史件禁改写边界}} → {{按 08 §3 出正文、住历史区口径处置}}
- {{术语替换的行级豁免承载}} → {{term-scan 行级标记承载原文，不改写}}
- {{已审面再次修改}} → {{该面随批重过对应审面}}

### 2.2 验收面差分

- 纯文档/制度批可按本型验收面差分替代红绿口径（红→绿为缺省，例外由型件承载）
- 内容/结构轻量双审（两席独立出具报告，[B|W|N]+file:line）
- 全量门禁不回退；词面新增文字零命中
- 引用一致核对：正文逐字引用须有源文引用区逐字对应行

### 2.3 报告口径差分

- 审包自包含：任务书全文+白名单净增量 diff+必要源文片段，不含仓库访问授权
- 双审结论逐条对照表（finding→处置→审面映射）随批留档
